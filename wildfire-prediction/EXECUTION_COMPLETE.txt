ARCHITECTURE HIGHLIGHTS
================================================================================

Encoder (Downsampling):
  12 channels → 32 → 64 → 128 → 256
  Each stage: Double Conv + SE Block + Max Pool

Bottleneck:
  256 → 512 channels with SE block

Decoder (Upsampling):
  512+256 → 256 → 128 → 64 → 32 → 1
  Each stage: Upsampling + Skip Connection + SE Block

SE Blocks:
  - Squeeze: Global average pooling
  - Excitation: FC layers for channel recalibration
  - Provides attention without heavy computation
